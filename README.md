# Clinic Management System

## About the Project

The Clinic Management System is a web-based application developed to manage clinic-related activities efficiently. It provides different modules for managing doctors, patients, doctor visits, lab tests, prescribed tests, and receptionist-related activities.

The system is developed using ASP.NET MVC architecture with C# and provides a structured interface for clinic management.

## Features

- Doctor Management
- Patient Management
- Doctor Visit Management
- Lab Test Management
- Prescribed Test Management
- Receptionist Management
- Account and Login Management
- Home Page
- Database Connectivity
- User-Friendly Interface

## Technologies Used

- ASP.NET MVC
- C#
- HTML

## How to Run the Project

1. Download or clone the repository.
2. Open Visual Studio.
3. Open the `Clinic.WEB.csproj` file or the solution file, if available.
4. Configure the database connection in `Web.config` if required.
5. Restore the required NuGet packages.
6. Build the project.
7. Run the application using Visual Studio.

## Project Architecture

The project follows the ASP.NET MVC architecture:

- **Model:** Manages application data and business-related structures.
- **View:** Displays the user interface using Razor views.
- **Controller:** Handles application requests and coordinates between models and views.
